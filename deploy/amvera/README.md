# Размещение в Amvera

При подключении полного репозитория используются корневые `Dockerfile` и `amvera.yml`.

Для загрузки через панель Amvera подготовь `source.tar.gz` с исходниками в корне архива, без `node_modules`, `dist`, `.git`, `server/storage` и скриншотов. Загрузи в Code этот архив, `Dockerfile` из данной папки и корневой `amvera.yml`. Этот Dockerfile распаковывает исходники и запускает Node-сервер, который отдаёт React-сайт и API.

Настройки: Docker, порт 80, постоянный каталог `/data`, одна реплика. Раздел Data обновлять исходниками не нужно: здесь остаётся `db.json` основного сайта.

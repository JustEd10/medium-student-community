# Медиум — твой круг возможностей

Учебный сайт для адаптации иностранных студентов и студентов-мигрантов по странице «01 · Концепция» в Figma. В нём есть главная, вход, регистрация, профиль, знакомства, вопросы, помощь с учёбой, рейтинг, сообщения и меню. Реализация охватывает все типы экранов из 17 макетов ПК и 31 мобильного состояния.

![Главная на ПК](docs/screenshots/desktop-home.jpg)

## Для кого создан Медиум

Основная аудитория — иностранные студенты и студенты-мигранты, которые осваиваются в новом университете. Им бывает трудно общаться на языке обучения, разобраться в устройстве кампуса и найти знакомых. Местные студенты участвуют как собеседники и помощники: объясняют учебные темы, отвечают на вопросы и практикуют иностранный язык.

Сначала пользователь выбирает языки общения, затем интересы. В «Знакомствах» выбор языка доступен сразу; студенты с большим числом общих языков появляются выше. В «Вопрос-ответе» можно спросить о первых шагах в университете. В «Помощи с учёбой» — попросить разобрать тему и указать в описании понятный язык.

## Опубликованный сайт

[Открыть Медиум](https://medium-bob01.amvera.io/). Обновлённая версия опубликована в Amvera через Safari и работает по HTTPS. После повторного запуска подтверждены статус «Запущено» и 1 из 1 реплик.

## Запуск

Для запуска нужен Node.js 20 или новее. Выполни команды в папке проекта:

```sh
npm ci
npm run dev
```

Открой http://127.0.0.1:5173/. Чтобы собрать и проверить готовую версию:

```sh
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Открывай его через HTTP-сервер: двойной щелчок по `index.html` не запустит приложение. В маршрутах используется `#`, поэтому сайт работает на статическом хостинге и в подпапке проекта.

## Как попробовать сайт

1. Открой «Вход», выбери Алину Ахметову в поле «Демо-пользователь» и нажми «Открыть демоверсию».
2. В «Знакомствах» сначала выбери язык общения, затем уточни интересы в фильтрах. Открой профиль студента и нажми «Написать».
3. В «Вопрос-ответе» открой вопрос о студенческом билете и оцени ответ от 1 до 5 звёзд.
4. Открой «Рейтинг». Если изменить оценку, она заменит старую. Звёзды не начисляются повторно.
5. В «Помощи с учёбой» открой «Нужна помощь» и опубликуй запрос. Переключись на демо-пользователя Вэя и откликнись через «Могу помочь». Затем вернись к автору запроса, выбери помощника, нажми «Помощь получена» и поставь оценку.

Можно создать отдельный учебный аккаунт и заполнить профиль. Демо-персонажи, вопросы и сообщения вымышлены.

## Страницы

| Адрес | Что работает |
| --- | --- |
| `#/` | Главная и переходы в разделы |
| `#/login`, `#/register` | Вход, регистрация, ошибки формы, показ пароля, деморежим |
| `#/profile` | Сохранение имени, направления, курса, языков, интересов и описания |
| `#/people`, `#/people/wei` | Поиск, фильтры, общие языки, карточки, профиль студента |
| `#/questions`, `#/questions/q1` | Публикация, фильтры, ответы и оценки |
| `#/questions?tab=rating` | Общий рейтинг, сумма звёзд, число оценок, среднее |
| `#/study` | Открытые запросы, поиск предмета, отклики |
| `#/study?tab=need` | Публикация запроса, выбор помощника, завершение, оценка |
| `#/chats`, `#/chats/c1` | Диалоги, сообщения, сохранение переписки |
| `#/menu` | Все разделы, смена RU/EN и выход |

На телефоне карточки располагаются в одну колонку, используется нижняя навигация, список диалогов и переписка открываются отдельно, рейтинг доступен отдельной вкладкой. Сохранены исходный фон, логотип, фиолетовые, голубые и мятные акценты, светлые карточки и скругления. Текст на пастельных кнопках темнее для читаемости.

Короткие анимации сопровождают открытие меню, переключение вкладок и выбор звезды. При включённом уменьшении движения они отключаются. Подробности — в [описании анимаций](docs/MOTION.md).

## Рейтинг

Рейтинг складывается из оценок за ответы и завершённую помощь с учёбой. Каждая оценка принимает целое значение от 1 до 5. Оценивать может только автор вопроса или запроса; свой ответ оценить нельзя. При повторном выборе новая оценка заменяет прежнюю, а число оценок остаётся тем же. При одинаковой сумме выше стоит участник с большим числом оценок. Если совпадает и оно, порядок определяется по имени.

## Где хранятся данные

Профили, вопросы, ответы, оценки и сообщения хранятся в `localStorage` текущего браузера. Состояние синхронизируется между вкладками одного браузера и одного адреса сайта. Очистка данных сайта сбрасывает изменения. `localhost` и `127.0.0.1` имеют разные хранилища.

В этой учебной версии работает frontend. Для переписки между разными людьми и устройствами нужен backend с серверной авторизацией, модерацией и базой данных. Локальная регистрация сохраняет соль и PBKDF2-хеш пароля. Защищённой серверной авторизации здесь нет. Для регистрации нужен HTTPS либо `localhost`/`127.0.0.1`, где доступен Web Crypto. Используй учебный пароль.

RU/EN переводит интерфейс; пользовательские тексты и названия предметов остаются на языке ввода.

## Проверки

```sh
npm test
npm run test:install
npm run test:e2e
```

Сборка и 7 тестов правил приложения прошли. В браузере Codex проверены пользовательские сценарии при ширине 1440, 768, 390 и 320 пикселей, выбор звёзд клавиатурой и доступность через axe. Результаты и ограничения описаны в [отчёте](docs/REPORT.md).

В GitHub Actions прошли 33 end-to-end теста production-сборки в Chromium, Firefox и WebKit, 7 тестов логики и сама сборка. Проверены 240 сочетаний языка, маршрута и ширины и 18 гостевых вариантов на телефонах, 18 вариантов анимаций с обычным и уменьшенным движением, клавиатура, формы, чат, оценки и 84 автоматические проверки доступности. [Успешный запуск CI](https://github.com/JustEd10/medium-student-community/actions/runs/37683050939) проверил код коммита `139fd03`. В локальной среде macOS отдельные процессы браузеров были заблокированы; кроссбраузерная проверка выполнена на Ubuntu в CI. Workflow использует официальные [checkout](https://github.com/actions/checkout), [setup-node](https://github.com/actions/setup-node) и [upload-artifact](https://github.com/actions/upload-artifact).

В режиме разработки можно открыть инструменты проверки:

- `http://127.0.0.1:5173/scripts/preview.html`: экран заданной ширины и проверка axe;
- `http://127.0.0.1:5173/scripts/capture.html?width=390&height=844&route=%2F`: мобильный экран для скриншота.

Они не входят в production-сборку.

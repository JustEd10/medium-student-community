# AI-собеседники

Три явно обозначенных вымышленных персонажа работают через обычные личные диалоги:

- Ли Вэй — только китайский.
- Пьер Мартен — французский и начальный русский с ошибками в падежах.
- Диего Гарсия — испанский, английский и русский.

У персонажей нет паролей, почты для входа и сессий. Они не публикуют вопросы, не модерируют и не имеют доступа к другим диалогам. Анкеты создаются при запуске сервера только при включённой настройке; повторный запуск сохраняет существующие блокировки и удаления.

## Закрытая настройка

Создайте `chat-bots.json` в выбранном `DATA_DIR`, вне публичных файлов и Git, с правами `600`:

```json
{
  "enabled": true,
  "provider": "gemini",
  "apiKey": "",
  "model": "gemini-3.5-flash-lite"
}
```

Заполните `apiKey` только в закрытом файле. Не помещайте ключ в клиентские переменные `VITE_*`, сообщения, скриншоты, команды терминала или коммиты. В интерфейс возвращаются только имя провайдера и готовность настройки; готовность не означает проверенный доступ к API.

Альтернатива: `provider: "groq"`, `model: "qwen/qwen3.8-27b"` и ключ Groq. Это Groq, а не платный Grok/xAI. Провайдер переключается вручную. Автоматических переключений, платных резервных моделей и повторов запросов нет. После смены провайдера пользователь должен заново дать согласие.

Сервер также понимает `CHAT_BOTS_ENABLED=1`, `CHAT_BOT_PROVIDER`, `CHAT_BOT_MODEL`, `GEMINI_CHAT_API_KEY` и `GROQ_API_KEY`. Значение `CHAT_BOTS_ENABLED=0` отключает отправку. Перезапустите сервер после первичного включения для создания анкет. Без ключа анкеты доступны, но отправка AI отключена. Обычные диалоги продолжают работать.

## Условия провайдера

API Gemini имеет отдельные от подписки Google AI лимиты. Для бесплатного теста используйте проект Free без включённого биллинга; код не может определить тариф ключа. Если привязать оплачиваемый проект, запросы могут тарифицироваться.

Перед запуском проверьте [регионы Gemini](https://ai.google.dev/gemini-api/docs/available-regions) и [условия API](https://ai.google.dev/gemini-api/terms). Россия не указана среди доступных регионов. Ограничение касается и пользователей приложения; сервер в Варшаве его не устраняет. API нельзя предоставлять аудитории младше 18 лет. В бесплатном Gemini текст может использоваться для улучшения моделей. Подготовленный адаптер сам по себе не разрешает публичный запуск для российской аудитории.

Для альтернативы сверяйте [модели Groq](https://console.groq.com/docs/models) и [лимиты](https://console.groq.com/docs/rate-limits) своего аккаунта. Наличие бесплатного тарифа не гарантирует доступность из любой страны и постоянную квоту. Живое качество персонажей и доступность нужно проверять отдельно с разрешённым ключом.

## Очередь и данные

Перед отправкой пользователь подтверждает возраст и передачу текста внешнему AI. В запрос входят системные правила персонажа и максимум 12 последних неудалённых сообщений одного диалога, суммарно не более 10 000 символов. Профили, почты и другие диалоги не передаются. Личные данные, введённые в сам текст сообщения, не удаляются автоматически — их нельзя отправлять.

Один ответ на диалог одновременно; глобальный обработчик последовательный с паузой 4 секунды между запросами. Собственный защитный лимит: 20 попыток на весь сайт и 10 на пользователя за сутки UTC. Ошибочные попытки тоже считаются. Это лимиты приложения, не официальная квота провайдера. Модерация GigaChat использует свою существующую очередь.

Задание и счётчики сохраняются вместе с сообщением до обращения к API. `clientId` предотвращает повторные ответы на повторную доставку. После перезапуска незаконченные задания требуют явного повтора. Перед сохранением ответа повторно проверяются участники, блокировки, согласие и неизменность использованного контекста. Отзыв согласия останавливает дальнейшую обработку, но уже отправленный провайдеру запрос отозвать нельзя.

Проверки `tests/chat-bots.test.js` используют заглушки HTTP и не расходуют токены. API-тесты используют отдельный временный `DATA_DIR` с пустым ключом. Реальные языковые ответы и соблюдение роли моделью эти тесты не доказывают.

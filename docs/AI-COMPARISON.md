# Проверка помощника РЭУ

На шести общих студенческих вопросах GigaChat 3 Lightning и GigaChat 2 Pro дали корректные ответы по предоставленным выдержкам. Неподтверждённых цен, сроков и номеров кабинетов в рассмотренных ответах не обнаружено. Преимущество Pro по точности на этой небольшой выборке не выявлено, поэтому рекомендовано оставить настроенную Lightning и продолжать расширять источники.

## Реальный прогон

API `/models` подтвердил доступность обеих моделей. Выполнено 12 генераций, по шесть каждой; фактические версии из ответа провайдера — `GigaChat-3-Lightning:32.4.16.3` и `GigaChat-2-Pro:2.0.30.01`. Использованы одинаковые вопросы, база версии 3 и параметры temperature=0.1, max_tokens=700. Запросы последовательные, без повторов; конфигурация рабочего сайта не менялась.

| Модель | Генераций | Медианное время полного запроса | Всего токенов из API |
| --- | --- | --- | --- |
| GigaChat-3-Lightning | 6 | 270 мс | 1513 |
| GigaChat-2-Pro | 6 | 1026 мс | 1555 |

Вопросы: поиск расписания, отсутствие письма с логином, срок выдачи студенческого билета, документы для библиотеки, стоимость/наличие места в общежитии, приглашение иностранному студенту. Каждый ответ просмотрен вручную в сопоставлении с выбранными выдержками. Для неизвестных сроков и стоимости обе модели сообщили отсутствие данных. У ответа о студенческом билете выбранная выдержка о библиотеке не содержит сроков выдачи; безопасный отказ модели не означает, что поиск нашёл идеальный источник.

Дополнительно проверены шесть одинаковых сценариев справочника для каждого маршрута: ВУС, ВУЦ, библиотека, социальный отдел, конкретный международный отдел и неизвестный деканат. Эти ответы выполняются без генерации и **не засчитываются в качество моделей**. Результаты с исключёнными служебными метаданными: [JSON](ai-comparison.json).

Это один прогон без повторений на узком наборе вопросов, а не общий рейтинг моделей. Время включает сетевой запрос и обработку помощником; последовательный порядок, прогрев и нагрузка провайдера могут влиять на результат. Число токенов не является ценой: тарифы моделей здесь не сравнивались. Перед дальнейшим переключением стоит расширить набор вопросов, добавить проверки сложных инструкций и повторные прогоны.

## Изменения справочника

- ВУС: кабинет 100 по сообщению владельца проекта; корпус пока не уточнён. Источник этой поправки явно показан отдельно от официальных контактов.
- Сектор записи читателей НИБЦ: шестой корпус, кабинет 301, ул. Зацепа, 43 — [официальная страница](https://www.rea.ru/science/biblcentr/struktura/sektor-zapisi-chitateley).
- Отдел стран Европы, Америки, Африки и Ближнего Востока: третий корпус, кабинет 649 — [официальная страница](https://www.rea.ru/mejdunarodnaya-deyatelnost/otdel-stran-evropyi-ameriki-afriki-i-blijnego-vostoka). Это не универсальный кабинет всех международных подразделений.
- ВУЦ: отдельное подразделение, VUC@rea.ru; номер кабинета в выбранной выдержке не подтверждён — [официальная страница](https://www.rea.ru/structure/departments/vuts).

Сведения о кабинетах выдаются из справочника; уточнения владельца не помечаются как факты официального сайта. Старые сохранённые ответы можно повторно запросить: изменение версии базы инвалидирует кэш.

## Проверки и статус

50 автоматических тестов прошли, сборка Vite прошла. Закрытая локальная конфигурация для пробных запросов находится вне репозитория с правами 600, каталог — 700. Ключ не записан в результаты, документацию или Git. Проверки доработки выполнены локально; размещение выполняется отдельно. [Настройка и запуск сравнения](AI.md).

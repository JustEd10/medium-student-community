## Найденные и исправленные ошибки

| Проблема в присланной версии | Исправление |
| --- | --- |
| Ошибка записи файла скрывалась, сервер мог сообщить об успехе и оставить несохранённые данные в памяти | Сначала записывается временный файл и заменяется `db.json`; только после успеха меняется состояние в памяти. При сбое возвращается 503. |
| Повреждённое сохранение могло незаметно замениться начальным состоянием | Ошибка чтения или проверки файла останавливает запуск и сохраняет исходный файл. Отсутствующий файл по-прежнему означает первый запуск. |
| Асинхронная ошибка регистрации или входа могла миновать обработчик Express 4 | Добавлена обёртка, передающая отклонение Promise в обработчик ошибок. |
| Два запроса регистрации одной почты могли пройти проверку до вычисления хэша | Почта повторно проверяется после вычисления хэша, перед сохранением. |
| Сессии основного сайта не истекали | Добавлен срок семь дней; истёкшие и старые бессрочные сессии не восстанавливаются. |
| Токен принимался без корректного Bearer-заголовка | Разбор заголовка стал строгим; регистр слова Bearer допускается любой. |
| Неверные типы могли превращаться в текст или число; длинные поля обрезались | Добавлены проверки типов и ограничений. Булевы оценки и курс не принимаются. Слишком длинный текст отклоняется. |
| Учебная страница очищала весь localStorage при выходе | Использует только ключи `medium.lesson.*`; сессия и язык основного сайта сохраняются. |
| Запоздавший ответ опроса мог вернуть прежнее состояние после действия, входа или выхода | Ответы привязаны к версии состояния и сессии; опрос отменяется при изменении, действия выполняются по очереди. |
| Повторный клик или Enter могли повторно отправить запрос | Добавлена блокировка отправки и объединение одинаковых незавершённых действий. |
| После отправки мог исчезнуть новый текст, уже введённый в ожидании ответа | Поле очищается только если его содержимое и открытый чат не изменились. |
| Учебная оценка выбиралась числом | Теперь это пять доступных кнопок-звёзд. |
| Поле ответа могло распирать мобильную учебную страницу | Добавлены ограничения ширины и перенос длинного текста. |
| Сохранённые данные могли попасть в Docker-контекст | Добавлен `.dockerignore`; рабочий `server/storage` исключён из архива исходников. |

## Хранение и размещение

Учебный API намеренно хранит данные в массивах и сбрасывает их при перезапуске, как требует задание. Основной сайт хранит их в `DATA_DIR/db.json`; сессии двух интерфейсов независимы.

Для размещения основной версии нужен постоянный каталог `/data` и одна реплика Node-процесса. JSON-хранилище не синхронизирует несколько реплик. При обновлении следует сохранить копию существующего файла и использовать тот же `DATA_DIR`; аккаунты сохранятся, владельцы старых бессрочных токенов войдут заново.

Проект остаётся учебным: известные логины учебной страницы и открытый вход в демо-профили оставлены для показа задания. Локальные проверки выполнены без запуска Docker; инструкция размещения находится в README.

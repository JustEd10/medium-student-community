# AI-помощник РЭУ

В разделе «Вопрос-ответ» можно спросить AI отдельно или включить автоматический ответ при публикации. Автоматический ответ хранится в вопросе отдельно от ответов студентов, не участвует в рейтинге и исчезает при удалении вопроса. Текст вопроса передаётся в GigaChat; профили, переписка и учётные данные пользователей не передаются.

RAG ищет подходящие выдержки в `server/knowledge/reu.json` по словам и их нормализованным формам, затем передаёт выбранные фрагменты модели. Это локальный текстовый индекс без отдельной векторной базы. Начальная база покрывает расписание, учётную запись, электронные сервисы, общежития, социальную поддержку и обзор информации для иностранных студентов. Это не полный архив документов университета. Источники проверены 11.10.2026; их нужно обновлять при изменениях. Если подходящих фрагментов нет, запрос модели не выполняется. Ссылки берутся из базы, а не из ответа модели.

## Серверная настройка

Ключ хранится только в переменной `GIGACHAT_AUTH_KEY` либо в закрытом файле `${DATA_DIR}/gigachat-config.json` с правами 600. Поля файла: `authKey`, необязательные `scope`, `model`, `caFile`. Не помещать этот файл в Git, сборку, публичные каталоги или раздел Amvera «Код». В Amvera использовать закрытый постоянный каталог «Данные».

По умолчанию: scope `GIGACHAT_API_PERS`, модель `GigaChat-3-Lightning`. Переменные `GIGACHAT_SCOPE`, `GIGACHAT_MODEL`, `GIGACHAT_CA_FILE` переопределяют настройки. Корневой сертификат из официальной инструкции Сбера хранится в `server/certificates`; он применяется только к запросам GigaChat вместе со стандартными корнями Node. Глобальные настройки доверия не меняются, проверка TLS не отключается.

OAuth: `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`; генерация: `https://api.giga.chat/v1/chat/completions`. Токен кешируется до истечения срока. Запросы ограничены пятью попытками за пять минут на пользователя и двумя одновременными генерациями на процесс. Для JSON-хранилища предусмотрена одна реплика приложения. Ошибка AI не отменяет публикацию вопроса. После перезапуска незавершённый ответ можно запросить повторно.

## API

- `GET /api/app/assistant/status`: готовность настройки, без секретов.
- `POST /api/app/assistant` с `question`: отдельный ответ, нужна активная сессия.
- `POST /api/app/assistant` с `questionId`: ответ для своего вопроса или вопроса, модерируемого администратором. Готовый ответ повторно возвращается без расхода токенов.
- `addQuestion` принимает `autoAI` (boolean, по умолчанию true).

[Авторизация GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api), [сертификаты](https://developers.sber.ru/docs/ru/gigachat/certificates), [источники РЭУ](https://www.rea.ru/studentu).

# Термины из «Отработка 2. Frontend»

| Термин | Определение | Пример в проекте |
| --- | --- | --- |
| Frontend | Часть сайта, с которой пользователь взаимодействует в браузере. | Страницы, формы, карточки и кнопки Медиума. |
| HTML | Язык разметки, который задаёт структуру и смысл элементов страницы. | `header`, `nav`, `main`, `section`, `form`, `footer`. |
| CSS | Язык стилей, который задаёт оформление и расположение элементов. | Цвета, отступы, шрифты, сетки и скругления в `src/styles.css`. |
| JavaScript | Язык программирования, который добавляет поведение странице. | Фильтрация, валидация, сохранение профиля и пересчёт рейтинга. |
| Responsive | Адаптация интерфейса к ширине экрана и способу взаимодействия. | Одна колонка и нижняя навигация на телефоне; несколько колонок на ПК. |
| Cross-browser | Совместимая работа сайта в разных браузерах. | Подготовленные сценарии Playwright для Chromium и Firefox. Их успешный прогон ещё требуется подтвердить. |
| Accessibility | Возможность пользоваться сайтом людям с разными особенностями, включая использование клавиатуры и экранного диктора. | Подписи полей, видимый фокус, диалог, ошибки формы, звёзды с доступными названиями. |
| DOM | Объектное дерево документа, через которое браузер и JavaScript работают с содержимым страницы. | React обновляет дерево при отправке ответа, смене фильтра или выборе оценки. |

# Скриншоты проверки

Свежий комплект локальной сборки. Использованы вымышленные аккаунты и отдельное хранилище, рабочая база не затрагивалась. ПК: 1440 × 900, телефон: 390 × 844, планшет: 768 × 1024. Захват всей страницы может быть выше окна. Safari снят в нативном окне на ПК; панель вкладок обрезана, содержимое сайта сохранено.

# Развёртывание в Amvera

Сайт: [medium-bob01.amvera.io](https://medium-bob01.amvera.io/).

Сайт работает в приложении `medium`, аккаунте `bob01`, регионе `msk0`. Для публикации через Safari в раздел Code загружены `Dockerfile` и `source.tar.gz`, затем запущена сборка. Создан бесплатный внешний HTTPS-домен. Дополнительные реплики и тариф не менялись.

Docker собирает React/Vite на Node.js 24 и отдаёт только `dist/` через Nginx на порту 80. Последний архив содержит исходники коммита `f7a4a8193e84598d12ac93760e7b4495eef1d075`: 35 файлов. SHA-256 архива: `43f451d2761fd0415107b2bdb09e872344378bef476f42b32456184ff881363b`.

Архив загружен через Safari в коммит Amvera `229a0124429180cb1e32672ab1cadf89250ef662`. Сборка завершилась с кодом 0; новая версия доступна по внешнему адресу. Настройка желаемого количества реплик оставлена равной 1. HTML, JavaScript и CSS доступны по HTTPS с кодом 200 и совпадают с локальной production-сборкой. Форма «Нужна помощь» использует всю доступную ширину, поле «Твой вопрос» поддерживает несколько строк, кнопка «Помощь получена» имеет белую надпись. Верхняя навигация повторяет сохранённый макет Figma: отдельные кнопки 116 × 24 пикселя, промежутки 28 пикселей, Inter Medium 12, сиреневый фон с белым текстом и светло-голубой фон с чёрным текстом для текущего раздела. Область нажатия увеличена до 44 пикселей по высоте. На компактных экранах промежутки уменьшаются, мобильная навигация сохранена. Вёрстка проверена вручную при ширине 1440, 901 и 390 пикселей; автоматические тесты в этой редакции не запускались. Подтверждения находятся в `docs/study-form-update.json`.

В предыдущей редакции [GitHub Actions](https://github.com/JustEd10/medium-student-community/actions/runs/37687775820) проверил 7 тестов логики и 33 браузерных теста. Этот результат относится к прежнему коммиту `bbc2929`, а не к текущему обновлению.

## Повторная публикация через Safari

Подготовь рядом с репозиторием папку с двумя файлами:

```sh
mkdir -p ../medium-amvera-upload
cp deploy/amvera/Dockerfile ../medium-amvera-upload/Dockerfile
git archive --format=tar.gz --output=../medium-amvera-upload/source.tar.gz HEAD src public index.html package.json package-lock.json vite.config.js postcss.config.js tailwind.config.js
```

В Amvera открой «Репозиторий», вкладку Code и нажми «Загрузить данные». При первой публикации загрузи оба файла; для обновления исходников достаточно `source.tar.gz`. Затем открой «Конфигурация» и нажми «Собрать». Если конфигурационного файла нет, сначала сохрани окружение `docker`, инструмент `docker`, Dockerfile `Dockerfile` и порт 80 кнопкой «Применить». Архив должен называться `source.tar.gz`: Docker распакует его при сборке. Дождись статуса «Запущено» и проверь внешний HTTPS-адрес.

Чтобы опубликовать изменения из GitHub, снова упакуй исходники и загрузи их через Safari. Автоматическая синхронизация с GitHub пока не подключена.

Профили, сообщения, вопросы и оценки сохраняются в браузере посетителя. Для хранения данных на сервере и переписки между устройствами нужна серверная часть.

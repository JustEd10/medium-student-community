## Мобильные состояния

| Номера в макете | Реализация |
| --- | --- |
| 01–06 | Главная, вход, регистрация, свой профиль, знакомства, профиль студента |
| 07–11 | Список вопросов, ответы и их оценки |
| 12–15 | Могу помочь / Нужна помощь, форма, подсказка, выбор помощи |
| 16 и 18 | Отдельные список диалогов и экран переписки |
| 17 | Модальное меню |
| 19–21 | Вкладка рейтинга в вопросах и ссылка из помощи |
| 22–26 | Пять работающих состояний оценки ответа от 1 до 5 |
| 27–31 | Рейтинг после каждой оценки, рассчитанный из данных |

Вместо чисел `111111` и имён `А А / Б Б` из макета используются вымышленные примеры; рейтинг рассчитывается по оценкам. Новые вопросы, ответы, отклики и сообщения создаются пользователем в браузере. Макеты Figma в этой работе не изменялись.

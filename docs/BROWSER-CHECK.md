# Проверка в браузерах

Проверена локальная сборка `http://127.0.0.1:4221/`. Постоянные данные основного сайта находятся в отдельном временном каталоге; аккаунты и публикации вымышленные. Учебный API хранит данные в памяти. Рабочий сервер Amvera, реальные аккаунты и платные AI-запросы не использовались.

## Браузеры и сценарии

| Браузер | Подтверждённая версия | Проверено |
| --- | --- | --- |
| Codex In-app Browser, Chromium | Chrome/155.0.0.0 в User-Agent запроса к сайту | Главная, вход, знакомства, карточка, форум, создание вопроса, ответы, рейтинг, помощь, профиль, чат; учебный вход, список, отправка ответа и «Мои записи», демо-массив. |
| Safari | 27.0.1; AppleWebKit/605.1.15, совпадает с установленной версией приложения | Главная, вход, знакомства, форум после входа, меню; учебный вход, список, отправка ответа, общий список и «Мои записи». |

Публикация вопроса после входа прошла без `id is not defined`. Ответы учебного сценария видны одновременно в общем списке и личных записях. Проверка второго браузера выполнялась на ПК; мобильные и планшетные ширины проверены в Chromium. Нативные iPhone/Android не использовались.

## Адаптив

В Chromium проверены главная, знакомства, карточка студента, список вопросов, вопрос с ответами, рейтинг, помощь, профиль и чат. Каждая страница проверена при ширине 390, 768 и 1440 px: **27 сочетаний**. Во всех случаях `document.documentElement.scrollWidth` равен `clientWidth`. [Результаты измерений](screenshots/verification/responsive-check.json). Полоса прокрутки может уменьшать фактическую ширину содержимого на 15 px.

Форма входа дополнительно снята при 390 × 844 и 1440 × 900. Учебная страница проверена на ПК и телефоне. Снимки всей страницы могут быть выше заданного окна; мобильная нижняя навигация фиксируется у границы видимого окна.

## Клавиатура и доступность

- Главная: пройден порядок Tab, ссылки и кнопки имеют видимое выделение фокуса.
- Вход: «Почта или логин» → «Пароль» → «Показать пароль» → «Войти». Во всех четырёх точках выделение — сплошная обводка 3 px.
- Меню Chromium: после открытия фокус на «Закрыть»; последовательность из 11 Tab остаётся внутри диалога. Escape закрывает меню и возвращает фокус на «Открыть меню».
- Меню Safari после исправления: Shift+Tab с первого элемента переводит на «Выйти», Tab возвращает на «Закрыть», Escape возвращает на кнопку открытия. Настройки Safari не изменялись; для обхода ссылок требуется Option+Tab либо включённая полная клавиатурная навигация.
- Учебная страница: статические и динамические поля имеют связанные подписи, ошибки форм объявляются через live region, элементы управления получили общую видимую обводку фокуса.
- Белый текст навигации на `#8555c9` — **5,07:1** вместо 2,67:1 на прежнем фоне. [Требование W3C к контрасту обычного текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

Это проверка перечисленных сценариев. Она не заменяет полный аудит всех страниц со скринридером или проверку всего сайта на соответствие WCAG.

## API и сборка

- `npm test`: 72 теста, все успешны, без пропусков; API-тесты используют временные данные и отдельный порт 3999.
- `npm run build`: успешно.
- **14 реальных запросов curl**: приветствие, время, случайное число, демо-массив, список и элемент, отказ без токена, вход, создание вопроса и связанного ответа, личные записи, защита удаления, удаление своего вопроса, 404 после удаления.

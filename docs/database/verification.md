# Результат локальной проверки

Выполнены 93 автоматических теста без ошибок и сборка React. В проверках использовались только временные каталоги и вымышленные аккаунты. Рабочая база и внешние AI API не использовались.

Отдельный сценарий выполнил 24 HTTP-запроса к настоящему локальному серверу. Подтверждены SQL JOIN, сохранение пользователей, вопросов, ответов и сессий после перезапуска; запрет изменения чужой записи; откат двух транзакций при искусственной ошибке SQL; восстановление удалённой записи из логической копии; отсутствие сессий в восстановленной базе и успешный повторный вход.

Проверены интерфейсы основного сайта и учебной страницы. В браузере выполнены вход, публикация вопроса и ответа; раздел «Мои записи» получил название вопроса из JOIN. Ошибок и предупреждений в консоли не обнаружено.

На 10 000 ответах запрос COUNT по question_id: без индекса 0.1666 мс, с индексом 0.0020 мс, отношение 81.6. Это медиана серий после прогрева на одном компьютере, не обещание ускорения HTTP или рабочего сайта. План изменился с SCAN answers на SEARCH answers USING COVERING INDEX answers_question.

Postman не установлен, поэтому его запуск и скриншоты не заявляются. Подготовлена коллекция запросов для отдельного ручного прогона. Репозиторий на GitHub и рабочий сервер этой доработкой не обновлялись.

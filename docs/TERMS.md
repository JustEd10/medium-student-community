# Термины

Фронтенд: часть сайта, которую пользователь видит в браузере и с которой взаимодействует.

Бэкенд: серверная часть сайта, которая отвечает за логику, она скрыта от глаз пользователя .

HTML: язык разметки для структуры страницы. Теги обозначают заголовки, текст, ссылки, формы и другие элементы.

CSS: язык стилей для оформления страницы. Он задаёт цвета, шрифты, размеры и расположение элементов.

JavaScript: язык программирования, который добавляет поведение странице: обработку кнопок, проверку форм и фильтрацию данных.

Адаптивность: способность страницы подстраиваться под размер экрана. На телефоне колонки могут складываться в одну, а навигация менять расположение.

Кросс-браузерность: корректная работа сайта в разных браузерах.

Доступность: возможность пользоваться сайтом с клавиатуры, экранным диктором и другими средствами. Для неё важны подписи полей, видимый фокус и читаемый текст.

DOM: дерево объектов, которое браузер строит из разметки страницы. JavaScript может обращаться к этим объектам и менять содержимое страницы.
